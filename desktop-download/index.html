Télécharger pour Windows

Installer en 3 étapes

  1. Ouvrez le fichier téléchargé (360annonces-CRM-setup.exe, dans « Téléchargements »).
  2. Si Windows affiche « Windows a protégé votre PC » : cliquez sur Informations complémentaires, puis sur Exécuter quand même.
  3. Cliquez sur « Suivant » puis « Terminer ». L'application se lance et un raccourci apparaît sur le Bureau. Aucun mot de passe administrateur n'est demandé.

Pourquoi cet avertissement ?

Windows se méfie de tout programme dont l'éditeur n'a pas encore payé un certificat de signature. Ce message ne veut pas dire que le fichier est dangereux : il signale seulement que Windows ne connaît pas encore cet éditeur. Vous pouvez comparer l'empreinte plus bas.

  1. Ouvrez le fichier .dmg puis glissez « 360annonces CRM » dans le dossier Applications.
  2. Au premier lancement, faites un clic droit (ou ctrl + clic) sur l'application, puis Ouvrir.
  3. Confirmez avec « Ouvrir » dans la fenêtre qui apparaît. C'est nécessaire une seule fois.

Pourquoi cet avertissement ?

macOS bloque les applications qui ne sont pas encore « notariées » par Apple (programme payant). Clic droit > Ouvrir est la méthode prévue par Apple pour faire confiance à une application que vous avez choisie.

Si macOS annonce « l'app est endommagée » : ouvrez le Terminal et tapez xattr -dr com.apple.quarantine "/Applications/360annonces CRM.app"

  1. Téléchargez le fichier .AppImage (ou le paquet .deb sous Ubuntu/Debian).
  2. Rendez-le exécutable : clic droit > Propriétés > « Autoriser l'exécution », ou chmod +x 360annonces-CRM-linux-x64.AppImage.
  3. Double-cliquez dessus. Pour le .deb : sudo apt install ./360annonces-CRM-linux-x64.deb.

indisponible
Comment comparer ?

Dans PowerShell : certutil -hashfile "$env:USERPROFILE\Downloads\360annonces-CRM-setup.exe" SHA256

Dans le Terminal : shasum -a 256 ~/Downloads/360annonces-CRM-mac-arm64.dmg

Dans un terminal : sha256sum ~/Téléchargements/360annonces-CRM-linux-x64.AppImage

Les deux séquences doivent être identiques.
